# Hilta Nuusiku Iita — Personal Developer Portfolio

A React + Vite personal portfolio focused on practical software development, learning, and hackathon work.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Update content

- `src/data/projects.js` — project descriptions, status, features, technologies, and links.
- `src/data/skills.js` — skills / technologies.
- `src/data/learning.js` — currently learning areas.
- `src/App.jsx` — section content and layout.
- `src/index.css` — visual design, responsive layout, and theme styling.

### Project links

The GitHub links currently point to Hilta's supplied GitHub profile because individual repository URLs were not supplied. Replace the `github` values in `src/data/projects.js` with the actual repository URLs when available.

Demo links are intentionally not fabricated. Add a real URL in the `demo` field when one exists.
